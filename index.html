Subida YouTube

Herramienta de escritorio de uso personal para subir vídeos a YouTube.

Subida YouTube es una aplicación de escritorio para Windows que sube por lotes los vídeos de una carpeta local (por ejemplo, un disco externo) a un canal de YouTube del propio usuario, usando la API de datos de YouTube (YouTube API Services).

Qué hace

  • Lee los archivos de vídeo de la carpeta que el usuario elige en su propio ordenador.
  • Los sube al canal de YouTube que el usuario autoriza expresamente, con el título, la descripción y las etiquetas indicadas.
  • Muestra el progreso y genera un informe local con el enlace de cada vídeo subido.

Quién la usa

Es una herramienta interna de un solo usuario para migrar su propio contenido a su propio canal. No se ofrece al público ni tiene usuarios externos.
